# 連鎖捕り / Pair Capture

## 日本語

連鎖捕り！

4文字以上の語で、2マスの敵グループを連続して奪取。

連鎖捕り：4文字以上の語で、2マスの敵グループの一部を取ると、もう一方も続けて取れることがあります。

## English

Pair Capture!

Pair Capture: Capture a connected 2-cell enemy pair with a 4+ letter word.
